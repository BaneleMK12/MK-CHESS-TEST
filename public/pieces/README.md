# Chess piece artwork

The PNGs in this directory are converted from the Cburnett chess piece set
published in the Lichess repository:

https://github.com/lichess-org/lila/tree/master/public/piece/cburnett

The source set is credited to Colin M.L. Burnett and is distributed under the
Creative Commons Attribution-ShareAlike 3.0 license. The local `source/`
directory contains the original SVG files used to create the PNGs.
